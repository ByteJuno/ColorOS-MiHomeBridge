## Android 模拟控制

独立 instrumentation APK 在手机运行，无需 UiAutomation。24 项检查全部通过，模拟界面回调共 3 次；真实 provider 控制指令为 0。

- 合成 Toggle、ToggleRange、嵌套 Temperature/Range 和 Stateless 模板，核对 BooleanAction、FloatAction、CommandAction 的模板 ID、目标值和步长。
- 拒绝 NaN、无穷值与超范围值；温度 22.4 按 0.5 步长得到 22.5。
- 实际弹窗切换开关后等待回传确认；程序刷新和设置滑条进度不触发控制，拖动结束只触发一次本地数值回调，重连状态禁用控制。
- 切换模拟温控与场景行后，界面仅显示相应能力；执行场景只调用本地计数器。
- 使用手机上 MyDevices 的真实 IndicatorButtonView 类验证可操作与禁用状态，本地点击回调不连接家电。
- home-v04-simulated-dialog.jpg 为实际手机上的合成灯光界面，不代表家中已接入可调光灯。

首轮长时间后台传输测试被 ColorOS 清理了 instrumentation 进程，进程退出记录为 OTHER KILLS BY SYSTEM / Cached(nirvana)，并非模块 Java 崩溃。后续使用前台初始化及分段观测完成验证，没有为测试放开模块后台策略。

## 实现约束与未验收项

独立设备中心通道继续核对 Android 提供的发送 UID、包名、系统用户和 2.5 秒有效期；设置通道仍使用签名权限。指令需要当前可见租约、解锁、当前用户、最新可用状态，并逐次去重；断线恢复不重发家电指令。隐藏设备不参与桥接订阅。

主列表使用状态推送、10 秒心跳和 30 秒异常租约上限，最多 32 行。每张图不超过 16 KiB，每帧图像不超过 192 KiB。图片加载、绘制、压缩、散列及解码在有界工作队列执行；缓存按用户隔离，关闭桥接或切换用户清除。后台会话与两套原生界面分别报告适配情况。

按用户“只验证界面和模拟控制”的要求，未执行真实家电开关、调光、调温、场景，也未操作 PVE 插座。原生卡片完整控制链路对不同设备模板的实际效果仍待有合适家电后验收；本版提供常用快捷控件，复杂属性仍由米家详情承接。锁屏交互、系统用户切换、原生拖拽排序、经典主题和其他固件未完成实机验收。

米家“完全允许后台行为”设置继续保留，未改变全局 Hans 策略。本轮未修改屏幕超时，结束时实测为 600000 毫秒。0.3.0 APK 和源码备份于 .local/rollback-0.3.0/；历史验收见 validation-0.3.0.md，完整恢复证据见 validation-0.2.2.md。
